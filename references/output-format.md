# 输出格式规范

## 核心原则
- 投委会的输出使用 `message` 工具主动推送到飞书
- 禁止依赖自动路由
- 中间进度更新（出师校验通过、辩论完成、结论草案生成、审计通过、最终结论）都必须主动推送

## 格式化规则

### 列表替代表格（全体输出通用）
```
> **标题行**
> - 字段A：值
> - 字段B：值
>
> **标题行2**
> - 字段X：值
> - 字段Y：值
```

### 出身证摘要（列表格式示例）
```
> **锁定四：出身证摘要**
> - 最新价：25.83元
> - PE(TTM)：36.54
> - PB：3.36
> - 扣非净利润：××亿元
```

### 最终结论（分层列表格式示例）
```
## 评级总览
- 五级评级：⭐⭐⭐ 中性
- 置信度：🟡 中
- 操作建议：持有观察，不追入
- 合理估值区间：18-34元

## 核心判断
...分段文本...

## 操作建议
- 已持仓：继续持有，止损20元
- 未持仓：不建议当前价位追入
```

## 消息发送
- 使用 `message(action="send", channel="feishu", target="user:<open_id>", message="内容")`
- 超 3000 字节拆条，每条独立完整
- 同一个结论的拆条连续发送，不要等用户回复

## 进度推送时机
1. ✅ 出身证校验通过 → "出身证校验通过，进入阶段二：规则锚定与辩论"
2. ✅ 辩论完成 → "多空辩论完成。综合裁定：××评级" + 核心论据摘要
3. 📋 结论草案生成 → "结论草案已生成：××评级，已提交风控部审计"
4. ✅ 审计通过 → 完整最终结论
