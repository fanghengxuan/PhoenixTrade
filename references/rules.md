# Phoenix+ 执行铁律与约束

## 执行铁律（不可违反）

1. **阶段一未完成，阶段二绝不开工。** 这是最高优先级规则。
2. **锁定一未完成，禁止执行编排决策。**
3. **任何必填字段为空白（NA 除外），禁止继续下一步。**
4. **最终审计任一检查项未通过，禁止输出结论。**
5. **所有分析结论必须有锁定声明的数据支撑，严禁凭空推测。**
6. **所有金融数据必须通过 Python 脚本获取，禁止使用 web_fetch 自行网页抓取。**
   - 脚本路径：`scripts/stock_check_v614.py`
   - 调用方式：`exec(python3 scripts/stock_check_v614.py <代码> --json)`
   - 脚本返回结构化 JSON，从中提取所需字段填充模板

## 三阶段分工

| 阶段 | 内容 | 入口 | 出口 |
|------|------|------|------|
| 一 | 数据获取与核验 | 用户旨意 | 出身证摘要 |
| 二 | 规则锚定、估值、辩论 | 出身证摘要 | 结论草案（已审计） |
| 三 | 存档与输出 | 审计通过 | 最终结论 |

## 输出格式铁律

1. ❌ 禁止使用任何 Markdown 表格。一律用列表/分段文字。
2. ❌ 单条飞书消息上限 3000 字节（约 1500 中文字）。超出必须拆条。
3. ❌ 代码块单独一段，不可嵌入列表或表格。
4. ✅ 最终输出前做格式检查：含表格则重写、超长则拆分、代码块独立。

## 审计硬约束

- 结论草案必须提交风控部独立审计（sessions_send 通信）
- 收到核准通过前，禁止输出任何评级/操作建议
- 封驳最多 3 轮，第 3 轮仍不过 → 请人工介入
- 投委会不能自行代劳审计
